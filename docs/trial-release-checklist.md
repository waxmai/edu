# 试运营上线清单

## 1. 目标口径

适用场景：
- 单机构受控部署
- 内部试运行
- 小规模真实业务试用
- 对外演示环境

不适用场景：
- 完全开放公网注册
- 无运维值守的大规模正式商用

---

## 2. 上线前必须完成

### 2.1 代码与构建
- [ ] `git status --short` 为空，确认无临时脏改动
- [ ] 前端 `cd frontend/web && npm run build` 通过
- [ ] 后端 `make ci` 通过
- [ ] `make generated-check` 通过，确认 Wire / Swagger 产物无漂移
- [ ] `make server-smoke` 通过

### 2.4 账号与权限

## 6. 当前建议结论

当前版本建议定义为：
- **受控试运营交付版**
- **可演示、可试用、可小规模真实业务运行**

当前版本不建议直接定义为：
- **完全放开公网的大规模商用终版**
